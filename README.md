# Faslulhaq Farees | Portfolio

My personal portfolio website, built with **Next.js**, **React**, **Tailwind CSS** and **Framer Motion**.

🔗 **Live site:** https://faslulhaq.netlify.app

## About me

IT undergraduate at SLIIT, building full-stack web apps with the MERN stack and Spring Boot,
and shipping them with Docker and CI/CD. Looking for a software engineering internship.

## Features

- Responsive single-page design that works on desktop and mobile
- Typing effect, scroll animations and animated skill bars (Framer Motion)
- Projects, experience, skills and certifications driven from one data file
- Contact form and downloadable CV

## Tech stack

| Area | Tools |
|---|---|
| Framework | Next.js (App Router), React |
| Styling | Tailwind CSS v4 |
| Animation | Framer Motion |
| Icons | react-icons |
| Hosting | Netlify |

## Run locally

```bash
cd faslulhaq-portfolio-next
npm install
npm run dev
```

Then open http://localhost:3000.
